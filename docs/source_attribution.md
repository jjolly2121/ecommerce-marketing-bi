# Dataset Sourcing and Attribution

## Primary source

Google Analytics, “BigQuery sample dataset for Google Analytics ecommerce web implementation.”

- Dataset: `bigquery-public-data.ga4_obfuscated_sample_ecommerce`
- Documentation: https://developers.google.com/analytics/bigquery/web-ecommerce-demo-dataset
- BigQuery export schema: https://support.google.com/analytics/answer/7029846
- Public dataset access/pricing notes: https://cloud.google.com/bigquery/public-data
- Sample period: 2020-11-01 through 2021-01-31

The dataset contains obfuscated GA4 event-export data that emulates the Google Merchandise Store’s real-world web e-commerce implementation. Google explicitly notes that placeholders and limited internal consistency may exist.

No source data is copied into this repository. All analytical outputs must be generated by queries against the public BigQuery dataset. Derived SQL, documentation, and dashboard design are original project work.
